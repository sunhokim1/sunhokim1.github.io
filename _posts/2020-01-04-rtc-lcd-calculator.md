## 프로젝트 개요
- **목표**: RTC 시계와 계산기 기능을 하나의 AVR 시스템에 통합
- **사용 기술**: ATmega128A, I2C, FSM, 스택
- **주요 장치**: DS1307, LCD1602, 4×4 키패드, 버튼

![RTC와 LCD, 키패드를 연결한 브레드보드](/assets/images/rtc-board.jpg)
*하드웨어 구성 사진*

## 구현 내용
- **시계**
    - I2C로 DS1307의 시간·날짜 읽기
    - 키패드를 통한 시간·날짜 수정
- **계산기**
    - 사칙연산과 괄호 입력
    - 스택을 활용한 계산식 처리
    - Backspace·취소 기능 제공
- **화면과 입력**
    - LCD1602 4비트 인터페이스 사용
    - 버튼과 FSM을 이용한 시계·설정·계산기 모드 전환
    - 버튼·키패드 입력 시 부저 출력

## LCD 초기화와 계산식 처리
- **LCD**: 데이터시트 순서에 따라 초기화 후 4비트 인터페이스로 출력
- **계산식**: 키패드 입력을 스택에 저장하고 연산 처리 후 결과 표시
- **입력 편집**: Backspace와 취소 기능으로 입력 수정

## 문제 해결 1: LCD 출력 오류
- **문제점**: LCD 화면 출력 불량
- **원인**: 4비트 모드 초기화 순서 오류
- **해결**
    - 데이터시트의 초기화 순서 확인
    - 8비트 설정 세 번 강제 초기화 후 4비트 모드 설정
- **결과**: 발표자료에 초기화 순서 수정 기록

## 문제 해결 2: 버튼 중복 입력
- **문제점**: 버튼 한 번을 눌렀을 때 여러 데이터 출력
- **원인**: 딜레이 없이 동일한 누름을 반복 처리
- **해결**: 딜레이를 추가해 반복 입력 방지

## 회로 확인
- 버튼 동작 불량: 결선 오류 확인 후 풀다운 구조로 수정
- RTC 통신: DS1307의 오픈 드레인 SDA·SCL에 풀업 저항 필요
- LCD 시간 오차: 화면 갱신 딜레이 주기 조정
