## 프로젝트 개요
- **목표**: Linux 디바이스 드라이버 기반 스마트 팬 구현
- **주요 장치**: Jetson Orin Nano, PWM 모터, 로터리 엔코더, 초음파 센서, LED
- **동작**: 엔코더·거리 이벤트에 따른 팬 상태 변경

![스마트 팬 시연 화면](/assets/images/fan-photo.jpg)

## 구현 내용
- **초음파 센서**
    - GPIO 10μs 트리거 펄스 출력
    - Echo 시간 측정 → 거리 계산 → 사용자 공간 전달
- **엔코더**
    - S1·S2 GPIO 인터럽트에서 상태 전이 해석
    - 회전량 누적 및 `read`를 통한 회전량·버튼 상태 전달
    - 스핀락을 이용한 공유 데이터 동시 접근 보호
- **팬과 상태 제어**
    - PWM 주기·듀티 설정을 통한 팬 속도 제어
    - 사용자 공간에서 전달된 속도 값 검사
    - 입력 이벤트에 따른 상태 변경 및 드라이버 연동

## 회로와 커널·사용자 공간 연결
- **장치 입력**: 초음파 센서와 로터리 엔코더의 신호를 GPIO로 수신
- **드라이버 처리**: 센서값과 엔코더 데이터를 사용자 프로그램에 전달
- **출력**: 사용자 프로그램의 상태에 따라 PWM 모터와 LED 제어
- **회로 확인**: 센서·엔코더·모터 연결과 PWM 설정 확인

![스마트 팬 기능 회로도](/assets/images/fan-schematic.jpg)

## 문제 해결 1: PWM 모터 미동작
- **문제점**: 모터 미동작
- **원인**: PWM 핀 설정 오류
- **확인 항목**: PWM 핀·채널 설정 및 하드웨어 연결

## 문제 해결 2: 엔코더 인터럽트 오류
- **문제점**: 엔코더 입력 인터럽트 불량
- **원인**: 풀업 저항 누락
- **확인 항목**: 엔코더 입력 회로 및 풀업 저항 구성
