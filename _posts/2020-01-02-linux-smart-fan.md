## 프로젝트 개요
- **목표:** Linux 디바이스 드라이버를 활용한 스마트 팬 구현
- **구성:** PWM 모터, 로터리 엔코더, 초음파 센서, LED
- **제어:** 엔코더와 거리 이벤트에 따라 팬 상태 변경

![스마트 팬 시연 화면](/assets/images/fan-photo.jpg)
*스마트 팬 시연 화면*

## 구현 내용
- 초음파 센서에 10μs 트리거 펄스를 출력하고 Echo 시간으로 거리 계산
- GPIO 인터럽트에서 엔코더 회전량을 누적해 `read`로 전달
- 인터럽트와 읽기 함수의 공유 데이터에 스핀락 적용
- PWM 듀티로 팬 속도 제어, 상태 머신과 메인 프로그램으로 모듈 통합

![스마트 팬 하드웨어 연결도](/assets/images/fan-circuit.jpg)
*스마트 팬 하드웨어 연결도*

## 문제 해결
- **모터 미동작:** PWM 핀 설정 오류를 확인
- **엔코더 인터럽트 오류:** 풀업 저항 누락을 확인
- **점검 항목:** 소프트웨어와 함께 핀 설정, 배선, 입력 신호 조건 확인
