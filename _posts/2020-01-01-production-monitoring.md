## 프로젝트 개요
- **목표:** 조립 단계별 부품 검사와 작업 현황 모니터링
- **구성:** STM32 NUCLEO-F411RE, Jetson Orin Nano, 웹캠, 작업자·관리자 PC
- **사용 기술:** 객체 검출, UART, TCP/IP

![생산 공정 모니터링 시스템 구성도](/assets/images/production-flow.jpg)
*현장 장치, 작업자 PC와 관리자 PC의 연결*

## 구현 내용
- 카메라와 Jetson을 사용해 조립 부품 검출 및 검사
- STM32에 LED, 부저, 버튼을 연결해 현장 제어
- 작업자 화면에서 제품 선택, 작업 진행·일시정지와 검사 결과 제공
- 관리자 화면에서 작업 이력과 품질 정보 관리
- STM32–작업자 PC는 UART, 작업자–관리자 PC는 TCP/IP 사용

![모델 5 평가 결과와 데이터 전략](/assets/images/production-model.jpg)
*최종 데이터 전략과 모델 5 평가 결과*

## 객체 검출 실험
- **선택:** 부품 종류·개수·위치 확인을 위해 YOLO26n 사용
- **실험:** 새 레시피에 필요한 데이터를 줄이기 위해 학습 데이터 구성을 비교
- **레시피 테스트:** 50장, precision 98.9% / recall 99.9% / mAP50 99.5%
- **일반화 테스트:** 18장, precision 88.1% / recall 95.5% / mAP50 92.9%
- **데이터 전략:** 조립 단계 이미지와 좌우 반전 증강을 사용하고 변경 단계·취약 부품 데이터를 선택적으로 추가

*수치는 발표자료의 모델 5와 해당 평가 데이터 기준.*
